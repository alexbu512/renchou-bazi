## Step 2：真太阳时换算

**使用 web_search 查询出生城市的精确经纬度**。

查询格式：`"[城市名] 经纬度"` 或 `"[城市名] longitude latitude"`

换算步骤：
1. 获取出生城市经度（东经度数）
2. 经度时差 = (出生地经度 - 120) × 4 分钟（东经>120为正，<120为负）
3. 均时差（按出生月份）：
   - 1月约-3至-13分 | 2月约-14分 | 3月约-5分 | 4月约0分
   - 5月约+4分 | 6月约+2分 | 7月约-6分 | 8月约0分
   - 9月约+10分 | 10-11月约+16分 | 12月约+11至+2分
4. 真太阳时 = 出生钟表时间 + 经度时差 + 均时差

**子时特殊处理（重要）**：
子时横跨两日（23:00-01:00），传统命理分为早子时和晚子时：
- **晚子时**：当日23:00-24:00 → 时柱为子时，但**日柱仍取当日**，年月柱同当日
- **早子时**：次日00:00-01:00 → 时柱为子时，**日柱需换算为次日**，年月柱视次日而定

操作步骤：若真太阳时换算后落在23:00-01:00范围内，需询问：
> "您的出生时间换算后在子时（23:00-01:00）范围内，请确认具体时间是 23点多（晚子时，日柱取当日）还是0点多/1点前（早子时，日柱取次日）？"
确认后再查日柱万年历。

**时辰边界处理**：
- 若真太阳时距时辰分界线不足15分钟，须告知用户存在时辰争议
- 建议排两个时柱分别参考，或结合人生经历验证

向用户报告：
> "您的出生地[城市]位于东经[X]度，真太阳时为：[时间]（北京时间[原时间] [±X]分），对应[时辰]时（[地支]时）。"

## Step 3：四柱排盘

**读取 `references/solar-terms.md` 和 `references/day-pillar.md`**

### 3.1 年柱
- 查 solar-terms.md 该年立春精确时间
- 出生时间（真太阳时）在立春**前**：年柱取**上一年**干支
- 出生时间在立春**后**：年柱取**该年**干支
- 1984年为甲子年，每年顺推

### 3.2 月柱
- 查 solar-terms.md 各年节气精确时间
- 判断出生时间位于哪两个"节"之间，确定月支
- 月干：查 wuxing-tables.md「五虎遁年法」，以年干+月支定月干

### 3.3 日柱
- **必须查 `references/day-pillar.md` 逐日对照表**
- 找到 YYYY-MM-DD 对应行，读取干支
- **严禁手工推算日柱**，避免计算误差

### 3.4 时柱
- 以真太阳时确定时支
- 时干：查 wuxing-tables.md「五鼠遁日法」，以日干+时支定时干

### 3.5 展示四柱

```
【四柱八字】
         年柱    月柱    日柱    时柱
天干：    X       X      [X]     X
地支：    X       X       X      X
（日主用[]标注）

【地支藏干】
年支 X：本气X、中气X、余气X
月支 X：本气X、中气X（或：仅本气X）
日支 X：本气X（或：本气X、中气X）
时支 X：本气X、中气X、余气X
```

## Step 4：大运排列

### 顺逆方向
- 阳年（年干甲丙戊庚壬）男命：**顺排**；女命：**逆排**
- 阴年（年干乙丁己辛癸）男命：**逆排**；女命：**顺排**

口诀：阳男阴女顺排，阴男阳女逆排

### 起运年龄

**操作步骤（必须严格按顺序执行）**：

**第一步：查出出生日前后所有节的完整时间列表**
从 solar-terms.md 找出出生年份及前后年份中，所有标注【节】的条目，按时间顺序排列。
十二节为：小寒、立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪

**第二步：找「最近的节」**
- **逆排**：在时间列表中，找到**距出生日（真太阳时）之前、时间差最小的那个节**
  - ⚠️ 必须是时间上最近的，不是月份上最近的
  - 例：出生日为5月12日，出生日前有两个节：立夏5月6日（差6天）、清明4月5日（差37天）
  - **正确答案：立夏（差6天）**，不是清明（差37天）
- **顺排**：找**距出生日之后、时间差最小的那个节**

**第三步：自检**
计算完后必须自问：「我找的这个节，是出生日前（或后）最近的节吗？有没有更近的节被我漏掉？」
如有疑问，重新列出出生月份前后3个月内的所有节逐一比较。

**第四步：计算**
- 天数差 = |出生日时分 - 节气时分|（精确到小时）
- 起运实岁 = 天数差 ÷ 3（保留一位小数）
- 起运虚岁 = 实岁 + 1（传统虚岁，出生即1岁）
- 余数处理：余不足0.5天忽略；余0.5-1天≈4个月；余1-2天≈8个月

### 大运干支排列
- 以月柱为基准，顺排则天干地支各向后推，逆排则向前推
- 每步大运管10年

```
【大运】  起运年龄：X岁（约XXXX年交运）

序      年龄       干支    约对应年份
起运前   0-X岁    [月柱]   XXXX-XXXX  （小运）
第一步   X-X岁    XX      XXXX-XXXX
第二步   X-X岁    XX      XXXX-XXXX
……（共列8-10步）

当前处于：第X步大运 [干支]，已走X年（共10年）
```

## 重要原则

1. **日柱必须查万年历表**，禁止手推
2. **节气须查精确时间**，不可用估计日期
3. **真太阳时必须实时查询经纬度换算**，不可依赖记忆中的城市经度
4. **时辰边界必须提示**，不可武断
5. **调候先于格局**：先读 qiongtong-baodian.md，后判格局
6. **空亡必须重新计算**：每次排盘必须查 kongwang-shenqiang.md 的旬空表，根据日柱干支确定所在旬，禁止凭记忆套用
7. **合局冲破须详推**：大运地支已成合局，若流年冲破，必须重新计算五行力量
8. **引用典籍须具体**：说明来自哪本书的哪个论断，不可笼统
9. **验盘优先**：正式分析前先验盘，用已知人生经历验证命盘准确性
10. **从格须四步验证**：未经 kongwang-shenqiang.md 第四节完整验证，不可轻率论从格
11. 若用户只需排盘，可在 Step 4 后询问是否继续完整分析

## ⛔ 报告输出禁止事项（违反将导致报告不可用）

**禁止1：不得在报告中展示推理过程**
报告只呈现结论。所有"等一下""我来算一下""辛金日主，我克之五行为木..."等内部推算过程一律不得出现在报告中。内部计算在给出报告前完成，用户只看到结果。

**禁止2：不得在报告中进行十神自我纠错**
十神必须在分析准备阶段算清楚。报告中绝不出现"等一下，重新确认：..."这类纠错过程。十神对照规则：
- **十神必须查 wuxing-tables.md 第四节「十神完整速查表」**，不得凭记忆推断
- 以辛（阴金）日主为例（必须牢记，此为高频错误点）：
  - 甲（阳木）= **正财**（辛克甲，阴阳异）
  - 乙（阴木）= **偏财**（辛克乙，阴阳同）
  - 丙（阳火）= **正官**（丙克辛，阴阳异）
  - 丁（阴火）= **七杀**（丁克辛，阴阳同）← 高频错误：丁绝非正官！
  - 戊（阳土）= **正印**（戊生辛，阴阳异）
  - 己（阴土）= **偏印**（己生辛，阴阳同）
  - 庚（阳金）= **劫财**（同金，阴阳异）
  - 壬（阳水）= **伤官**（辛生壬，阴阳异）
  - 癸（阴水）= **食神**（辛生癸，阴阳同）
- **核心规则**：克我者，阴阳同=七杀，阴阳异=正官。丁（阴）克辛（阴），同阴=**七杀**，非正官。

**禁止3：大运年龄段不得计算错误**
大运年龄段计算规则：
- 起运年龄（虚岁）= X岁，则第一步大运从X岁开始，到X+9岁结束
- 对应年份 = 出生年 + 起运虚岁
- 年龄段内的具体年龄 = 出生年份 + 当年年龄
- **前5年 = 大运开始年到第5年**，对应的年龄 = 起运岁数 到 起运岁数+4
- **后5年 = 大运第6年到第10年**，对应的年龄 = 起运岁数+5 到 起运岁数+9
- 输出前必须自我核验：年份区间是否与年龄区间一致（出生年+年龄=对应年份）

**禁止4：旺衰评分不得夸大**
身强身弱评分需综合考量，总分在-4到-2区间定为"偏弱"，-5到-7定为"弱"，低于-7才定为"极弱"。有日支临官以上根气者，最低只评"弱"，不得评"极弱"。

**禁止5：大运起运绝对不得用错节气**
逆排起运必须找出生日（真太阳时）**之前时间差最小的那个节**，不是当月之前的节，不是上一个月的节。
- ✗ 错误示例：出生5月12日，选了4月5日清明（差37天）→ 起运12岁，整个大运错位10年
- ✓ 正确示例：出生5月12日，应选5月6日立夏（差6天）→ 起运2岁
必须列出出生日前后3个月内的所有节进行比较，取时间差最小且在出生日之前的那个。

**禁止6：流年与原局同支不得判断为自刑**
自刑（午午/酉酉/辰辰/亥亥）必须是**命局内部**同时存在两个相同地支才成立。
流年地支与原局地支相同，只是"并临叠加"，效果是加重该支五行力量，无刑的破坏性。
- ✗ 错误：命局月支巳，流年乙巳 → 不能写"巳巳自刑"
- ✓ 正确：流年巳与原局巳并临，火势加重
- 自刑只能发生在：原局本身有两个相同支，或流年与大运地支相同（非原局）
