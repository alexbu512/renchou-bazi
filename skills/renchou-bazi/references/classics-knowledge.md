# 经典古籍核心论命知识

## 《渊海子平》核心要义

**地位**：子平八字体系奠基之作，徐大升所撰，为后世命理之祖。

### 格局体系（月令为纲）
- 以月令（月支）定格局，月令藏干透天干者为格神
- 八格：正官、偏官（七杀）、正财、偏财、正印、偏印、食神、伤官
- 取格原则：月支本气透干优先，次取中气，再取余气
- 格局清纯：用神一位，不受克破，为清贵之命

### 六亲宫位对应
- 年柱：祖上、父母（早年运，1-16岁）
- 月柱：父母、兄弟、工作环境（青年运，17-32岁）
- 日柱：自身（日干）、配偶（日支）（中年运，33-48岁）
- 时柱：子女、晚年成就（晚年运，49岁后）

### 六亲十神对应（男命）
- 正财为妻，偏财为父、情人
- 正官为女儿，七杀为儿子
- 正印为母，偏印为继母、祖母
- 食神为祖父、女儿（外孙）
- 比肩为兄弟，劫财为兄弟（争财）

### 六亲十神对应（女命）
- 正官为丈夫，七杀为情夫、偏夫
- 食神伤官为子女（食神为女儿，伤官为儿子，或反之，各派有异）
- 偏财正财为父亲
- 正印为母亲

## 《三命通会》核心要义

**地位**：万育吾撰，格局神煞集大成，内容最为详尽。

### 格局论命要点
- **正官格**：月令藏正官透干，喜印护官，忌伤官破格
- **七杀格**：月令藏七杀，须食神制杀或印化杀，"杀印相生"为贵
- **正财格**：月令藏正财透干，喜官印，忌比劫争财
- **偏财格**：同正财，但偏财主父（男命），忌比劫更甚
- **正印格**：月令藏正印，喜官生印，忌财破印
- **偏印格**：月令藏偏印，忌见食神（枭神夺食）
- **食神格**：月令藏食神，喜财，忌枭印夺食，忌七杀混局
- **伤官格**：月令藏伤官，"伤官见官为祸百端"（金水伤官除外），喜财泄秀

### 特殊格局
- **建禄格**：日干与月支五行相同且同阴阳（非长生），以月柱比肩论，不入八格
- **羊刃格**：日干帝旺在月支，阳刃，须七杀制刃，忌多见
- **从格**：四柱一气或日主极弱，随旺神而从
  - 从财格：日主弱，财星极旺，无印比，顺从财星
  - 从杀格：日主弱，官杀极旺，无印比，顺从杀星
  - 从儿格：日主弱，食伤极旺，顺从食伤
  - 从势格：财官食伤俱旺，日主无根，随势而从

### 神煞体系（重要者）

|------|------|------|
| 天乙贵人 | 日干起 | 逢凶化吉，贵人相助 |
| 文昌贵人 | 日干起 | 聪明好学，文才出众 |
| 天德贵人 | 月支起 | 消灾解难，福德深厚 |
| 月德贵人 | 月支起 | 同天德，阴阳相配 |

| 羊刃 | 日干起 | 刚烈、武职、意外伤 |
| 魁罡 | 日柱起 | 刚烈聪明，逢冲合大起大落 |

## 《滴天髓》核心要义

**地位**：刘基（刘伯温）原著，任铁樵注释，清代命理巅峰之作。强调气势流通，反对机械套格。

### 旺衰判断三原则
1. **得令**（最重要）：日主在月支是否处于生旺之地
   - 得令：长生、沐浴、冠带、临官、帝旺 = 有令（旺相）
   - 失令：衰、病、死、墓、绝 = 失令（休囚）
2. **得地**：日主在其他地支是否有根（长生、帝旺、墓库）
3. **得势**：天干是否有比劫帮身，或有印星生身

### 气势流通论
- 命局五行宜流通，忌阻滞
- 金生水、水生木、木生火、火生土——一路顺生为流通，主顺遂
- 某行过旺形成"堵塞"，需"通关"之物
- 通关举例：金木相战，水通关；水火相战，木通关

### 旺极宜泄不宜克
- 日主极旺：宜食伤泄秀，不宜再用比劫帮扶
- 日主极弱：考虑"从格"，顺其势，不宜强行扶助

### 天道地道人道
- 天干主动、主外，代表外在表现与上半生
- 地支主静、主内，代表内在根基与下半生
- 干支配合看人的行为选择与内外一致性

### 滴天髓重要论断举例
- "五阳从气不从势，五阴从势无情义"：阳干以气论，阴干灵活从势
- "官杀混杂看清浊，不清不浊任其取"：官杀混杂须区分清浊
- "伤官见官果难辨，可见不可见中寻"：伤官见官并非一概为凶

## 《子平真诠》核心要义

**地位**：沈孝瞻撰，命理格局论之集大成，最为系统规范。

### 用神专论
- **用神**：命局中对日主最有帮助、维持格局平衡的十神
- **相神**：辅助用神的十神（如正官格中的印星）
- **喜神**：生扶用神的五行
- **忌神**：克破用神的五行
- **仇神**：帮助忌神、克制用神的五行

### 格局成败论
**成格条件**：
- 用神有力（月令透干，得地有根）
- 相神辅助（如官印相生、财生官旺）
- 忌神有制（有力量压制忌神）

**败格条件**：
- 用神受克（忌神直接克破用神）
- 无相神辅助（用神孤立无援）
- 忌神当道无制（忌神当令无法压制）

### 各格成败举例
| 格局 | 成格 | 破格 |
|------|------|------|
| 正官格 | 官印相生，或官用财生 | 伤官见官，七杀混官 |
| 七杀格 | 食神制杀，或印化杀 | 杀旺无制，财生杀 |
| 正财格 | 财旺生官，或财印并用 | 比劫争财，劫多财破 |
| 食神格 | 食神生财，格局清纯 | 枭印夺食，七杀混局 |
| 正印格 | 官印相生，印用官护 | 财多破印，食伤泄印 |
| 伤官格 | 伤官生财，伤官配印 | 伤官见官（土金除外） |

### 格局高低
- 格局清纯、用神有力 = 命格高
- 格局混杂、用神受克 = 命格低
- 成中有败、败中有成——需分析轻重

## 《神峰通考》核心要义

**地位**：张楠撰，以"病药说"闻名，强调辩证论命。

### 病药说
- "命有病方为贵，无病不为奇"
- 命局有"病"（缺陷或过强之五行），大运流年来"药"（解病之神）时，方有成就
- 无病之命，平淡无奇；有病有药之命，大起大落，成就显著

### 辨病取药原则
- **病**：命局中过旺之五行、破坏格局之忌神
- **药**：能制约或化解病神的五行
- 药到病除：大运流年遇药，则发达
- 药去病来：大运流年病神再现，则受挫

### 反对机械套用神煞
- 神煞仅为辅助参考，不可单独论命
- 以五行生克制化为根本，灵活变通
- 不可执一而论，须全局观察

## 大运流年分析综合原则

### 大运分析要点（综合诸书）
1. 大运为10年的"大环境"，流年为当年的"引动"
2. 大运好、流年差：总体顺遂，当年有小波折
3. 大运差、流年好：总体不利，当年有机遇但难持续
4. **换运年**（大运交接之年）变动最大，需重点关注
5. 大运天干管前5年，地支管后5年（一家之说，亦有主张干支共管10年）

### 流年分析要点
- 流年与原局的冲合刑害为引动关键
- 流年与大运的关系：同气则力量叠加
- 太岁（流年地支）冲日支、年支：主重大变动（搬家、换工作、婚姻）
- 太岁冲月支：影响工作、父母、兄弟关系

### 断事方法（千里命稿综合）
1. 先看格局高低（决定人生天花板）
2. 看用神有力无力（决定格局能否发挥）
3. 看大运是否扶用神（决定人生各阶段顺逆）
4. 看流年引动哪个宫位和十神（决定具体事件）
5. 结合宫位论人事：年（祖/幼）、月（父/青）、日（配偶/中）、时（子/老）
