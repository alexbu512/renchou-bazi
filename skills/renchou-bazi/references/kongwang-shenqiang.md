# 空亡与身强身弱判定

---

## 一、空亡（旬空）

### 基本规则

六十甲子分六旬，每旬10天干配10地支，剩余2个地支无天干相配，即为该旬的"空亡"。

**查法：以日柱天干地支，找所在旬，剩余两支即为空亡。**

| 旬首 | 旬内十干支 | 空亡 |
|------|-----------|------|
| **甲子旬** | 甲子、乙丑、丙寅、丁卯、戊辰、己巳、庚午、辛未、壬申、癸酉 | **戌亥** |
| **甲戌旬** | 甲戌、乙亥、丙子、丁丑、戊寅、己卯、庚辰、辛巳、壬午、癸未 | **申酉** |
| **甲申旬** | 甲申、乙酉、丙戌、丁亥、戊子、己丑、庚寅、辛卯、壬辰、癸巳 | **午未** |
| **甲午旬** | 甲午、乙未、丙申、丁酉、戊戌、己亥、庚子、辛丑、壬寅、癸卯 | **辰巳** |
| **甲辰旬** | 甲辰、乙巳、丙午、丁未、戊申、己酉、庚戌、辛亥、壬子、癸丑 | **寅卯** |
| **甲寅旬** | 甲寅、乙卯、丙辰、丁巳、戊午、己未、庚申、**辛酉**、壬戌、癸亥 | **子丑** |

**速查口诀**：甲子戌亥空，甲戌申酉空，甲申午未空，甲午辰巳空，甲辰寅卯空，甲寅子丑空。

### 空亡的影响

**基本原则**：空亡之字，力量折半，作用减弱，但并非完全无用。

| 情况 | 影响 |
|------|------|
| 原局地支空亡 | 该支藏干力量减半，所代表的十神、六亲力量减弱 |
| 用神空亡 | 用神有力但打折，命格略降，人生顺遂度减弱 |
| 忌神空亡 | 忌神力量减半，反为吉，祸害减轻 |
| 大运空亡 | 该大运吉凶力量均减半，"好运不太好，坏运不太坏" |
| 流年空亡 | 当年感应迟钝，事情难以落实，易虎头蛇尾 |

### 空亡的解空

以下情况可"解空"（空亡地支力量恢复）：
1. **冲空**：与空亡地支相冲的地支出现（如空亡为戌，辰来冲，则戌解空）
2. **合空**：与空亡地支六合或三合的地支齐全（如空亡为亥，寅来合亥，则亥解空）
3. **填实**：大运或流年出现该空亡地支本身（如空亡为丑，大运或流年走丑，则暂时填实）

### 空亡断事要点

- 年支空亡：祖业难承，祖辈缘薄，幼年环境不稳
- 月支空亡：父母缘薄，兄弟助力有限，青年期事业基础不稳
- 日支空亡：配偶宫空，婚姻易有缺憾，感情路坎坷
- 时支空亡：子女缘薄，晚年依靠有限
- 用神空亡：努力打折，需加倍付出才能实现目标

### 实例说明（命主辛酉日）

辛酉日柱，查表：酉在甲申旬（甲申、乙酉、丙戌、丁亥、戊子、己丑、庚寅、辛卯、壬辰、癸巳），空亡为**午未**。

> 辛丑大运中，丑字本为好字（巳酉丑合金补印），但丑不在空亡之列，力量完整。
> 
> 若命主空亡为丑，则大运走辛丑，丑虽有用，力量仍打折，"好运没有预期中那么好"。

**使用时请根据命主实际日柱重新计算空亡。**

## 二、身强身弱判定体系

### 综合评分法

以下各项计分，正值为帮身，负值为克泄：

**得令（最重要，权重×2）**
| 月支状态 | 分值 |
|---------|------|
| 帝旺、临官 | +4 |
| 长生、冠带、沐浴 | +2 |
| 衰 | 0 |
| 病、死 | -1 |
| 墓、绝 | -2 |
| 胎、养 | -1 |

**得地（年月日时四支，各自计分）**
| 支中状态 | 分值/支 |
|---------|--------|
| 帝旺、临官（有根） | +2 |
| 长生（有根） | +1 |
| 墓库（有根） | +1 |
| 绝、死 | -1 |
| 无关联 | 0 |

**得势（天干，不含日干本身）**
| 情况 | 分值 |
|------|------|
| 比肩/劫财（每个） | +1.5 |
| 正印/偏印（每个） | +1 |
| 食神/伤官（每个） | -1 |
| 正财/偏财（每个） | -1 |
| 正官/七杀（每个） | -1.5 |

### 旺衰等级划分

| 总分 | 旺衰等级 | 用神取法方向 |
|------|---------|------------|
| ≥8分 | **极强（身旺）** | 以食伤泄秀为主，或财官为用 |
| 5-7分 | **偏强** | 食伤或财官为用，忌比劫印 |
| 3-4分 | **中和** | 视格局而定，调候优先 |
| 1-2分 | **偏弱** | 比劫或印星扶身 |
| ≤0分 | **极弱** | 考虑从格，或大力扶身 |

### 从格判定（极弱时必须考虑）

**从格条件**：日主极弱，且满足以下任一：
1. 四柱中无比劫、无印星（或有但极弱且被合绊）
2. 某一五行势力极旺（占命局70%以上力量）

**从格类型**：
| 从格 | 条件 | 用神 | 忌神 |
|------|------|------|------|
| 从财格 | 财星极旺，无印比 | 财、官 | 印、比劫 |
| 从杀格（从官） | 官杀极旺，无印比 | 官杀、财 | 印、比劫 |
| 从儿格（从食伤） | 食伤极旺，无印星 | 食伤、财 | 印星、官杀 |
| 从势格 | 财官食伤俱旺，日主无根 | 随旺神 | 印、比劫 |

**从格特征**：
- 从格命主随波逐流，顺势而为，反因"软弱"而成就
- 从格忌见印星、比劫（破从，反主凶）
- 大运扶从则顺，破从则凶

## 三、特殊强弱格局

### 专旺格（一气成象）
- 曲直格：甲乙木日主，木势极旺，地支寅卯辰或亥卯未全
- 炎上格：丙丁火日主，火势极旺，地支巳午未或寅午戌全
- 稼穑格：戊己土日主，土势极旺，辰戌丑未多见
- 从革格：庚辛金日主，金势极旺，地支申酉戌或巳酉丑全
- 润下格：壬癸水日主，水势极旺，地支亥子丑或申子辰全

专旺格用神：顺其势、同气比劫、食伤泄秀皆吉；忌克泄过甚

### 化气格（天干五合化气）
条件：日干与月干五合，且命局中化神有力（当令或地支多根），日主无其他根气

| 化气格 | 条件 | 用神 |
|-------|------|------|
| 化土格 | 甲己合，土旺 | 土、火 |
| 化金格 | 乙庚合，金旺 | 金、土 |
| 化水格 | 丙辛合，水旺 | 水、金 |
| 化木格 | 丁壬合，木旺 | 木、水 |
| 化火格 | 戊癸合，火旺 | 火、木 |

化气格：顺化神之势用事，忌克化神

## 四、从格成立的严格验证（防止误判）

从格是命理中最容易误判的格局，必须经过以下四步验证，全部通过才能论从格：

### 验证步骤

**Step A：日主有无根气**
查四支藏干，日主五行是否在任何一支中有根（长生、帝旺、临官、冠带、墓库均算有根）。
- 有根 → **不从**，回到普通身弱处理
- 无根或极微弱（仅余气，且该支被冲） → 继续Step B

**Step B：天干是否有比劫或印星透出**
检查年干、月干、时干中是否有与日主同气的比劫，或能生日主的印星。
- 有比劫透干 → **不从**（哪怕力量弱）
- 有印星透干 → **不从**（印可救日主）
- 均无 → 继续Step C

**Step C：旺神是否真正一统**
判断命局中最旺的五行是否占绝对优势（超过命局力量的65%）。
- 未达到绝对优势（如财官食伤分散） → 考虑**从势格**，但慎用
- 某五行一统全局 → 继续Step D

**Step D：印星是否藏而有力**
即使印星未透干，若藏在月支且为本气，仍可救日主，不能论从格。
- 月支本气为印星 → **不从**
- 印星仅为余气或藏于非月支 → 可论从格

### 从格破格条件

已成从格，若大运或流年出现以下情况，则**破从**，凶险：
- 出现比劫（帮日主，破从）
- 出现印星（生日主，破从）
- 日主五行大量出现（如从财格，大运走比劫旺地）

破从之年：命主常有重大挫折、事业失败、健康危机。
