# 穷通宝鉴调候用神（十干×十二月完整版）

## 使用说明
- 月令即出生月份的地支（节气换月，以"节"为准）
- 调候用神是命局中最需要的五行，如同命局的"药"
- 用神有透天干者力大，仅藏地支者力小
- 分析顺序：先调候，次格局，再扶抑

## 附：调候用神使用要点

1. **调候优先于扶抑**：命局寒热失调，即使格局再好也难发挥，必先调候。
2. **调候有力为贵**：用神透天干、得地支根气者为有力。
3. **调候无力为平**：用神仅藏支中、或被合绊，力量大减。
4. **调候全无为困**：命局完全缺调候用神，大运若不补足，人生多阻。
5. **夏生以水为贵，冬生以火为贵**：此为调候基本原则。
6. **土月（辰戌丑未）各有侧重**：辰月多水，未月多火，戌月多土，丑月多寒，具体看月支藏干。
