# 大运流年动态分析规则

---

## 一、大运分析框架

### 大运与原局的关系（静态层）

大运干支进入命局后，需逐一检查：

**天干关系**：
- 大运天干与原局四天干的五合、克制关系
- 是否合住喜用神（合绊，力量受限）
- 是否克制忌神（制凶，吉）
- 是否生助喜用神（吉）
- 是否生助忌神（凶）

**地支关系**（逐一检查以下六类）：
1. **六冲**：与哪个原局地支相冲？冲喜用地支为凶，冲忌神地支为吉
2. **三合局**：大运地支是否与原局两支构成三合？形成什么五行？对日主为喜为忌？
3. **六合**：大运地支与原局某支六合，合化为何？
4. **三会局**：大运地支是否补全原局三会局？
5. **相刑**：大运地支与原局地支是否构成三刑、二刑？
6. **相害**：大运地支与原局地支是否相害？

### 大运前后五年权重

- **前5年**：大运天干为主导，天干之喜忌主宰运势基调
- **后5年**：大运地支为主导，地支之冲合刑害影响更深层

---

## 二、流年分析框架

### 流年与原局的关系

流年干支相当于当年临时加入命局，产生的关系与大运类似，但**影响为期一年，力量较大运弱，但引动力强**。

**流年与原局的关键检查项**：
1. 流年地支是否冲原局年/月/日/时支（太岁冲本命最重要）
2. 流年地支是否与原局地支形成三合、六合（引动合局）
3. 流年天干是否与原局天干形成五合（合住关键天干）
4. 流年是否为喜用神（当年顺遂）或忌仇神（当年受阻）

### 太岁（流年地支）冲克影响

| 被冲宫位 | 影响范围 |
|---------|---------|
| 冲年支 | 祖业、故乡、早年积累有变动 |
| 冲月支 | 工作、父母、兄弟关系变动，职业转折 |
| 冲日支（配偶宫） | 婚姻、感情、居住环境大变动 |
| 冲时支 | 子女、下属、晚年计划受阻 |

---

## 三、大运与流年的叠加关系（核心）

这是动态论命最关键的层次，需分三步分析：

### 第一步：流年是否破坏大运已形成的合局

**规则**：大运地支与原局地支已形成的三合、六合，若流年带入冲支，则合局被破，原局已补的五行力量消失。

**重要案例**（命主辛酉日实例）：

原局：丁卯、乙巳、辛酉、甲午

辛丑大运（2019-2028）：
- 大运地支**丑**与原局**巳、酉**构成**巳酉丑三合金局**
- 金局成立 → 辛金日主得到强力补充，印星（土）也有丑中己土
- 这是大运最重要的利好

2027年丁未流年：
- 流年地支**未**与大运地支**丑**形成**丑未相冲**
- 丑被冲散 → **巳酉丑三合金局被迫瓦解**
- 失去金局支撑，辛金日主力量骤降
- 更有：巳午未三支齐全（原局巳午 + 流年未），构成**巳午未南方火局**
- 火局成立 → 火势大增，克制辛金日主，雪上加霜
- 流年天干丁火又是偏官（七杀），天干地支双重压力

**此类分析步骤**：
1. 列出大运地支与原局已成的合局
2. 检查流年地支是否冲该合局的关键字
3. 若冲：判断合局瓦解，重新计算命局五行力量
4. 检查流年地支是否与其他地支另起合局
5. 综合判断该流年吉凶

### 第二步：流年与大运干支的直接关系

| 关系 | 影响 |
|------|------|
| 流年生大运（喜用） | 大运正向力量增强，该年尤吉 |
| 流年克大运（喜用） | 大运力量受损，该年受阻 |
| 流年与大运同气 | 该五行力量叠加，效果加倍（喜则大吉，忌则大凶） |
| 流年合大运天干 | 大运天干被合绊，力量受制 |
| 流年冲大运地支 | 如上述丑未冲案例，合局瓦解 |

### 第三步：三运叠加（原局+大运+流年）

真正的断事需同时看三层：
- **原局**：命主天赋底牌（不变）
- **大运**：10年大环境（缓变）
- **流年**：当年具体引动（快变）

断事原则：
- 大运为喜，流年又为喜 → 该年大吉，事业/财运有突破
- 大运为喜，流年为忌 → 总体顺遂，当年有波折，注意具体宫位
- 大运为忌，流年为喜 → 总体艰难，当年有机遇，但难持续
- 大运为忌，流年又为忌 → 该年最凶，需谨慎行事

## 四、合局被破的专项规则

### 三合局被冲破

三合局（如巳酉丑合金）需三字全方成局。若其中一字被冲：
- 冲掉**库字**（如丑被冲）：金局散，力量全失
- 冲掉**旺字**（如酉被冲）：金局弱，力量减大半
- 冲掉**生字**（如巳被冲）：金局减弱，但仍有酉丑半合维持

### 六合被冲破

六合（如子丑合土）被另一字冲（如午冲子）：
- 合化瓦解，子午相冲的破坏力释放

### 三会局被破

三会局需三字全，缺一字则不成局。大运补全后若流年冲走：
- 三会局瓦解，力量同步消失

---

## 五、换运年（大运交接年）的特殊处理

大运交接的前后1-2年，新旧大运力量交替，是命局最不稳定的时期：
- 旧大运力量递减，新大运力量尚未完全到位
- 该段时间容易出现：职业转变、居所迁移、感情变化、健康波动
- 若换运年恰好遇到凶流年，则凶上加凶

---

## 六、流年岁运并临

当流年干支与大运干支相同（如大运辛丑，流年也是辛丑）：
- 力量极度集中，该五行影响翻倍
- 为喜用：该年可能有大突破、大机遇
- 为忌神：该年可能有严重事故或重大损失

## 八、"引动"理论——事件发生的触发机制

### 核心概念

命局如同一个静态的"舞台布景"，大运是改变舞台灯光的调节器，流年是登上舞台的"演员"。
但事件真正发生，还需要**引动**——即流年（或大运）的地支，激活了原局中某个宫位的干支关系。

### 引动的三种方式

**1. 冲动（最强引动）**
流年地支冲原局地支，该宫位对应的事情"被迫发生"。
- 冲年支：祖业、故乡、出行、与长辈关系变动
- 冲月支：职业、工作单位、父母兄弟关系、生活环境变动
- 冲日支（配偶宫）：婚姻大变动、居住迁移
- 冲时支：子女、下属、晚年规划受到冲击

**2. 合动（最吉引动）**
流年地支与原局地支合化，该宫位对应的事情"主动发生"，且多为吉事（若合化的五行为喜用）。
- 日支被合：感情/婚姻主动出现
- 月支被合：工作机会主动上门

**3. 刑动（复杂引动）**
三刑关系激活，性质复杂，吉凶取决于被刑的是喜神还是忌神。
- 寅巳申三刑：无恩之刑，事情发生后反目、背叛
- 丑戌未三刑：持势之刑，事情发生后争权夺利
- 子卯相刑：多主是非口舌、法律纠纷

### 宫位引动对应事件速查

| 被引动宫位 | 天干被引动 | 地支被引动 |
|----------|---------|---------|
| 年柱 | 祖上、幼年积累、根基 | 故乡、出行、与年长者关系 |
| 月柱 | 父母、兄弟、青年运 | 工作单位、居住环境、兄弟朋友 |
| 日柱天干 | 日主自身健康、主观行为 | — |
| 日柱地支 | — | 配偶、婚姻、合作关系 |
| 时柱 | 子女、晚年成就 | 子女、下属、晚年居所 |

### 双重引动（流年+大运同时引动同一宫位）

当流年和大运同时冲/合同一个原局地支时，引动力量极强：
- 该宫位代表的事情**必然发生**，且变化幅度极大
- 例：大运冲日支，流年同年又合日支 → 婚姻当年必有大变动（离合均有可能，看五行喜忌定吉凶）

## 九、换运年详细处理

每逢大运交接，通常在**起运年龄的整十倍数年**前后1-2年，表现为：

**换运信号（常见）**：
- 职业方向感模糊、想换工作但未动
- 感情状态不稳定、旧的关系结束但新的未开始
- 健康出现小问题，身体给出"信号"
- 搬家、出行、生活圈改变

**换运年分析步骤**：
1. 确定换运年份（起运年+整10倍）
2. 查当年流年干支，判断是否与旧大运或新大运产生冲合
3. 旧大运地支若被流年冲：旧大运提前结束，影响衰退加速
4. 新大运地支若被流年冲：新大运开局不顺，需1-2年才能稳定
5. 换运年若恰逢流年吉：新大运开局较好，顺利过渡
6. 换运年若恰逢流年凶：新旧交替期间波折较多，需谨慎
