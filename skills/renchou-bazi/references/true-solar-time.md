# 真太阳时换算规则

## 一、什么是真太阳时

命理排盘必须使用**真太阳时**（地方平太阳时），而非钟表时间（区时）。
原因：中国标准时间（北京时间，东八区）以东经120°为基准，实际出生地与120°之间存在时差。

## 二、换算公式

**真太阳时 = 出生钟表时间 + 经度时差 + 均时差**

### 经度时差
- 公式：`经度时差 = (出生地经度 - 120°) × 4分钟/度`
- 东经大于120°：结果为正，真太阳时比北京时间**早**
- 东经小于120°：结果为负，真太阳时比北京时间**晚**
- 示例：重庆约东经106.5°，时差 = (106.5 - 120) × 4 = **-54分钟**

### 均时差（方程式时差）
均时差是地球公转速度不均匀导致的修正值，每天不同，全年最大约16分钟。

| 月份 | 均时差（分钟，近似值） |
|------|-----------------|
| 1月初 | -3 |
| 1月末 | -13 |
| 2月中 | -14 |

| 6月初 | +2 |

**实际命理操作**：均时差最大约16分钟，对时辰判断影响有限。
精确排盘应加入均时差，但如果出生时间本身不确定（如"大概上午10点"），均时差可忽略。

## 四、历史时区问题（重要！）

中国历史上标准时间经历多次变更，排盘时需注意：

| 时期 | 标准时间说明 |
|------|------------|
| 1949年前 | 中国分五个时区，各地使用不同标准时 |
| 1949-至今 | 全国统一使用北京时间（东八区，UTC+8） |
| 台湾1945年前 | 使用日本时间（东九区，+1小时） |
| 战时（1940-1945）| 部分地区使用战时时间（夏令时，再+1小时）|

**1949年前出生的命主**：若出生地为上海、南京一带，当时使用"中原时区"（UTC+8，与现在一致）；西部地区有所不同，需具体查阅。

## 五、换算示例

**示例：重庆 1987年5月12日 13:00（北京时间）**

1. 经度时差：(106.5 - 120) × 4 = **-54分钟**
2. 均时差（5月中旬）：约 **+4分钟**
3. 真太阳时 = 13:00 - 54分 + 4分 = **12:10**

12:10 仍在**午时**（11:00-13:00）范围内，时柱不变。

**重要提醒**：真太阳时换算后，若时间落在时辰交界附近（前后15分钟内），应告知命主存在时辰争议，建议两个时辰都参考。

## 六、时辰临界处理原则

当真太阳时距时辰分界线（整点或奇数点）不足15分钟时：
- 告知命主具体时间和两个时辰的可能性
- 分别排盘，找与命主实际人生经历更符合的时柱
- 不可武断决定，须与命主核实
