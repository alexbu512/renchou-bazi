# 壬丑八字命理分析 (renchou-bazi)

专业八字命理排盘与分析，由具备命理学背景的用户深度定制开发。

支持两种使用方式：
- **Claude Code Plugin**（推荐）— 在 Claude Code CLI/桌面版中使用，含完整 references 数据
- **Claude.ai Skill** — 上传 `.skill` 文件到 claude.ai 网页版

---

## Claude Code Plugin 安装

```bash
# 从 marketplace 安装（上架后）
/plugin install renchou-bazi

# 本地测试：将整个仓库目录加载为 plugin
cc --plugin-dir /path/to/renchou-bazi
```

安装后，直接用自然语言触发：

```
帮我算八字
看看我的命盘
分析一下八字，1990年5月1日上午9点，北京，男
```

## ✨ 功能特点

- 🗓️ **真太阳时自动换算** — 实时查询出生城市经纬度，精确修正时辰
- 📅 **精确日柱万年历** — 内置 1920–2050 年逐日干支数据（寿星天文历），查表不手推
- 🌿 **节气精确时间表** — 1900–2050 年二十四节气精确到分钟，正确排月柱与大运
- 📖 **穷通宝鉴调候用神** — 十天干 × 十二月完整版，先调候后格局
- ⚖️ **身强身弱综合评分** — 得令/得地/得势三维评分，从格四步严格验证
- 🔮 **空亡判定** — 六旬旬空速查，命局/大运/流年分层分析
- 🌊 **大运流年动态分析** — 合局冲破专项规则，三运叠加断事，引动理论
- 📝 **完整命理报告** — 前七节专业分析（术语加括号解释）+ 第八节全通俗人生建议

## 📦 安装方法

1. 下载本仓库的 [`renchou-bazi.skill`](./renchou-bazi.skill) 文件
2. 打开 [Claude.ai](https://claude.ai) → 左下角头像 → **Settings** → **Skills**
3. 将 `.skill` 文件拖入安装，或点击上传

---

## 🚀 使用方法

安装后，在任意 Claude 对话中说：

> "帮我算八字" / "我要排盘" / "分析我的命盘"

即可触发，Claude 会依次询问姓名、出生年月日时、城市、性别，然后自动完成排盘与分析。

## ⚙️ 技术细节

- 节气数据来源：sxtwl 寿星天文历 Python 绑定
- 日柱数据：基于 1900-01-01（甲戌日）基准逐日推算并预存
- 空亡算法：六十甲子旬空标准算法
- 大运起运：精确到时分的节气差计算，虚岁报出
